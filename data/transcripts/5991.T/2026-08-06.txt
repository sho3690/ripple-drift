経営成績等の概況 （１）当四半期の経営成績の概況 当社グループの主要な事業分野であります自動車関連市場においては、国内の自動車生産台数は2,029千台で前年同期比3.7％の増加、北米（米国・カナダ）においては3,021千台で前年同期比0.2％の減少、中国では6,912千台で前年同期比6.9％の減少、タイでは384千台で前年同期比4.3％の増加となりました（いずれも台数は各拠点の決算期に応じた集計）。 もう一方の主要な事業分野であります情報通信関連市場につきましては、HDD（Hard Disk Drive）の世界出荷台数が前年同期比で増加し、データセンター向け高容量HDDが増加したことで、当社の主力製品でありますサスペンションの総需要は増加しました。 以上のような経営環境のもと、売上高は216,159百万円（前年同期比8.1％増）、営業利益は14,356百万円（前年同期比30.0％増）、経常利益は20,644百万円（前年同期比71.7％増）、親会社株主に帰属する四半期純利益は15,726百万円（前年同期比75.2％増）となりました。 セグメントの状況は以下のとおりです。 ［懸架ばね事業］ 懸架ばね事業は、在外子会社の円換算額の増加があるものの、米国での関税影響や一過性費用の計上等により、売上高は43,421百万円（前年同期比3.8％増）、営業損失は510百万円（前年同期は営業利益272百万円）となりました。 ［シート事業］ シート事業は、在外子会社の円換算額の増加や車種・品種構成の変化等により、売上高は74,075百万円（前年同期比0.6％増）、営業利益は1,793百万円（前年同期比0.4％増）となりました。 ［精密部品事業］ 精密部品事業は、自動車関連部品及びHDD用機構部品の数量増加等により、売上高は28,062百万円（前年同期比8.8％増）、営業利益は1,304百万円（前年同期比26.2％増）となりました。 ［DDS事業］ DDS（Disk Drive Suspension）事業は、データセンター向け高容量HDDの需要が引き続き増加し、HDD用サスペンションの売上数量が前年同期比で増加したことにより、売上高は37,637百万円（前年同期比24.0％増）、営業利益は9,057百万円（前年同期比43.1％増）となりました。 ［産業機器ほか事業］ 産業機器ほか事業は、半導体プロセス部品及び金属基板の数量が増加したことにより、売上高は32,962百万円（前年同期比16.2％増）、営業利益は2,711百万円（前年同期比66.7％増）となりました。 （２）当四半期の財政状態の概況 当第１四半期連結会計期間末の総資産については、現金及び預金が増加したほか、保有上場株式の時価評価により投資有価証券が増加しました。その結果、総資産は前連結会計年度末に比べ16,832百万円増加し、755,282百万円となりました。 負債については、長期借入金や未払法人税等が減少した一方、賞与引当金や設備関係電子記録債務の増加等により、前連結会計年度末に比べ1,400百万円増加し、286,815百万円となりました。 純資産については、親会社株主に帰属する四半期純利益による利益剰余金の増加及びその他有価証券評価差額金の増加等により、前連結会計年度末に比べ15,431百万円増加し、468,466百万円となりました。 （３）連結業績予想などの将来予測情報に関する説明 2026年５月11日に公表いたしました2027年３月期の通期連結業績予想から変更しておりません。なお、各事業セグメント別の業績予想に関しましては、以下のとおり、修正いたします。 2027年３月期通期（2026年４月１日～2027年３月31日） セグメントの名称 売上高 営業利益 前回予想 （A） 今回予想 （B） 増減 （B-A） 前回予想 （C） 今回予想 （D） 増減 （D-C） 百万円 百万円 百万円 百万円 百万円 百万円 懸架ばね 164,000 164,000 0 4,000 3,000 △1,000 シート 311,000 311,000 0 9,000 9,000 0 精密部品 108,000 108,000 0 5,000 5,000 0 DDS 144,000 144,000 0 30,000 31,000 1,000 産業機器ほか 133,000 133,000 0 11,000 11,000 0 合計 860,000 860,000 0 59,000 59,000 0 ２．
